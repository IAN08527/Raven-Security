# Raven

Criminal network analysis platform for law enforcement. Ingests case documents,
communication and financial records, and camera footage; extracts the entities and
relationships inside them; and presents a network where every link traces back to
the evidence that produced it. Runs entirely on premises with no third-party
network calls.
